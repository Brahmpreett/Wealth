# 💰 Wealth Levels

A visual exploration of how wealth scales across the world — from **$1 survival mode to billionaire god-mode**.

This project illustrates the massive differences in **income, lifestyle, and opportunities** at each wealth level through structured data and a simple interactive interface.

It’s designed to help people understand:

* How wealth changes lifestyle
* The professions typically associated with each level
* The economic percentile each tier represents
* The psychological and social realities of each wealth bracket

---

## 🌍 Concept

The app models **10 wealth tiers**, starting from extreme poverty and progressing to billionaires.

Each level includes:

* 💵 Daily income range
* 🧑‍💼 Typical professions
* 🌎 Global wealth percentile
* ⚖️ Pros and cons of reaching that level
* 📖 Lifestyle description
* 💡 Real-world examples

The goal is **perspective**, not judgment.

It highlights how different life can look depending on your position in the global economy.

## 🧠 Why This Project Exists

Most people think about wealth in terms of **salary**.

But wealth actually changes:

* your **risk tolerance**
* your **network**
* your **opportunities**
* your **time freedom**
* your **influence**

The difference between **$100/day and $100M/day** isn’t just money — it's an entirely different reality.

This project visualizes that spectrum.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Brahmpreett/Wealth.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Then open:

```
http://localhost:5173
```
